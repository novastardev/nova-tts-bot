## 🚀 Installation

### Step 1 — Clone the repository

```bash
git clone https://github.com/novastardev/nova-tts-bot.git
cd nova-tts-bot
```

### Step 2 — Create a Python virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### Step 3 — Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4 — Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` with your values:

| Variable | Required | Description | Example |
|----------|----------|-------------|---------|
| `TELEGRAM_BOT_TOKEN` | ✅ Yes | Bot token from @BotFather | `7777777777:AAF...` |
| `TTS_API_KEY` | ✅ Yes | TTS.ai API key | `sk-...` |
| `ALLOWED_CHAT_IDS` | ✅ Yes | JSON array of allowed user IDs | `[123456789, 987654321]` |
| `BOT_OWNER_HANDLE` | ✅ Yes | Your Telegram username | `@novastardev` |
| `TZ` | ❌ No | Monitor clock timezone | `Africa/Douala` |
| `PORT` | ❌ No | Web server port | `8080` |

### Step 5 — Get your Chat ID

1. Send `/start` to your bot on Telegram
2. Visit: `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. Find your `"id": 123456789` in the JSON response
4. Add it to `ALLOWED_CHAT_IDS` in `.env`

## 🤖 Telegram Bot Commands

| Command | Description |
|---------|-------------|
| `/start` | Welcome message — check your access |
| `/help` | List all available commands |
| `/tts` | Generate speech from text |
| `/voices` | Browse and select voices |
| `/settings` | Open voice settings |
| `/library` | View your saved speeches |
| `/health` | Check bot status (health endpoint) |

### How to use `/tts`

1. Send `/tts` to the bot
2. Send the text you want converted to speech
3. Wait a few seconds — the bot processes and generates audio
4. The bot sends back an **audio file** you can play
5. Replay any saved speech from `/library` anytime!

## 🌐 Web Interface (Server)

The web interface lets anyone use TTS without Telegram — just open it in any browser.

### Start the server

```bash
# Run the live monitor dashboard
python tts_monitor.py &
```

The server starts on port **8080** (or set via `PORT` env variable).

### Access URLs

| Path | Description |
|------|-------------|

## 🔧 Production Deployment

### Render.com (Auto-deploy)

1. Push this repo to GitHub
2. Go to [Render.com](https://render.com) → **New Web Service**
3. Connect your `nova-tts-bot` repository
4. Render reads `render.yaml` automatically
5. Set your `.env` variables in Render dashboard
6. Click **Deploy**!

### Manual Deployment with systemd

```bash
# Create service file for the bot
sudo tee /etc/systemd/system/nova-tts-bot.service > /dev/null << 'EOF'
[Unit]
Description=Nova TTS Bot
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/nova-tts-bot
ExecStart=/opt/nova-tts-bot/venv/bin/python bot.py
Restart=always
RestartSec=5
User=www-data

[Install]
WantedBy=multi-user.target
EOF

# Enable and start the bot
sudo systemctl daemon-reload
sudo systemctl enable nova-tts-bot
sudo systemctl start nova-tts-bot

# Check status
sudo systemctl status nova-tts-bot
```

### Expose on HTTPS with Caddy (Aleph Cloud)

```caddyfile
# /etc/caddy/conf.d/nova-tts-bot.caddy
handle_path /nova-tts/* {
    reverse_proxy localhost:8080
}
```

## 🐛 Troubleshooting

**Bot won't start**
- Check `TELEGRAM_BOT_TOKEN` is correct in `.env`
- Run `python bot.py` and read the error output
- Ensure `pip install -r requirements.txt` completed without errors

**"Access Denied" message**
- Your Chat ID isn't in `ALLOWED_CHAT_IDS`
- Get your ID from @userinfobot on Telegram
- Add it to `.env` and restart the bot

**Monitor shows offline**
- The bot must be running — the dashboard checks every 5 seconds
- Check `python bot.py` is actually running
- Check `bot.log` for errors

**TTS generation fails**
- Verify `TTS_API_KEY` is valid
- Check the API documentation at tts.ai
- Ensure the voice ID exists (use `/voices` to list them)

**Bot logs are empty**
- The log file is created when the bot starts
- If it's empty, the bot may not have processed any messages
- Check `/api/bot-logs` on the dashboard
